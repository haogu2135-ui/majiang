Create a single high-resolution transparent-background PNG asset sheet for a Godot mahjong game.

Subject: a unified 3D Chinese-style mahjong tile atlas / reference sheet, designed for later manual slicing into individual sprites.

Canvas and layout:
- 1536x1024 horizontal canvas.
- Transparent background only, no scene, no tabletop, no shadows cast onto any background plane.
- Arrange the tiles in a clean 8-column by 5-row grid with generous transparent padding between tiles.
- Every tile must fit fully inside its grid cell with no cropping, no overlap, and consistent scale.
- Use a slight top-down three-quarter view, about 20 to 30 degrees above the tiles, with all tiles facing the same direction.
- Keep identical camera angle, focal length, tile proportions, bevel size, and lighting for every tile.

Tile design:
- Warm white ceramic fronts with subtle porcelain translucency and very fine surface texture.
- Shallow rounded bevels, softly worn edges, premium game-piece finish.
- Sides are pale jade green with thin muted-gold rim accents, consistent on every tile.
- Engraved or inlaid markings, not printed flat stickers.
- Markings use restrained traditional Chinese mahjong colors: cinnabar red, deep jade green, ink black, and muted gold accents.
- Soft studio lighting from upper left, gentle contact shading on the tile bodies only, glossy ceramic highlights, no harsh reflections.

Tile contents:
- Include the full suited sets: 1-9 wan / characters, 1-9 bamboo, 1-9 dots.
- Include winds: East, South, West, North.
- Include dragons: red dragon, green dragon, white dragon.
- Include flower / season tiles with elegant small guofeng floral motifs.
- Include at least one tile back showing the pale jade and muted-gold back pattern.
- Markings should be clear mahjong tile markings only. Do not add captions, labels, explanatory text, UI text, watermarks, signatures, logos, or decorative background text.

Art direction:
- Premium 3D game asset render, guofeng but practical for a digital board game.
- Clean sprite-sheet readability over cinematic drama.
- Consistent silhouette and value contrast so each tile can be isolated and imported into Godot.
- The final image should look like one coherent asset atlas from a single modeled tile set, not a collage of unrelated renders.

Negative constraints:
- No people, no hands, no table, no cloth, no wood surface, no wall, no frame, no border.
- No random text, no Latin letters, no numbers outside the mahjong tile markings, no explanations.
- No perspective drift between tiles, no mismatched tile sizes, no different materials, no flat 2D icons.
- No extra props, dice, coins, chips, cards, menus, UI panels, or game board.
