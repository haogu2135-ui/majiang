# 国风 3D UI 设计师 Agent

执行日期：2026-07-05
工作目录：`/root/yunzhuo-mahjong-godot`

## Agent 职责

- 作为游戏 UI 设计师，负责把当前麻将 APP 的页面统一到商用国风 3D 视觉方向。
- 基于 `build/qa/pages/` 截图做页面审查，输出页面级设计目标、资产需求、安全区和验收标准。
- 给 `qa/agents/gpt_image_agent.md` 提供可直接执行的 GPT Image prompt，不调用非 GPT 生图工具。
- 对所有可玩麻将牌面保持强约束：牌面生成必须引用当前 `assets/tiles/*.png`，不得凭空臆想牌面文字或花色。
- 只定义视觉方向、prompt、验收标准和接入建议；最终 PNG 由 GPT 生图 agent 生成，代码接入由工程 agent 完成，截图回归由 UI screenshot agent 验收。

## 设计目标

整体方向：高端国风 3D 麻将桌游，像一个真实漆木、玉石、金属和锦缎构成的互动产品，而不是平面网页或程序画的装饰板。

关键词：

- 深墨绿牌桌和黑漆木框
- 温润玉色麻将牌和控件底座
- 暖金色边线、少量朱砂强调
- 月门、庭院、湖面、竹影、梅枝、宫灯
- 低对比背景，高对比文字和按钮
- 3D 倒角、接触阴影、PBR 材质、统一光源

明确禁止：

- 程序画出的散点、线条、轨迹、云团、调试色块冒充最终美术
- 非 GPT 生成最终 PNG
- 图中出现文字、随机数字、Logo、水印、真实品牌
- 生图直接生成可玩麻将牌面，除非使用当前同名 `assets/tiles/*.png` 作为参考图进行 GPT edit
- 背景把控件区域做得过亮、过花、抢 UI

## 页面级设计规范

### 1. 主菜单

- 第一屏应像真实 3D 牌桌房间：前景是深玉牌桌和金边 UI 框，远景是月门、湖面、山影、竹影和宫灯。
- 三个主入口卡片使用 GPT 生成的统一框体，程序只叠文字、图标、点击状态。
- 规则/战绩/成就/商店快捷按钮应是紧凑控件，不再有路线、节点、滴落、轨迹类程序装饰。
- 标题区和底栏需要低对比深色托底，保证小屏可读。

### 2. 设置面板

- 设置是黑漆木和玉石仪表盘风格，适合重复操作。
- 分区之间使用真实材质分隔，不依赖发光线条。
- 开关、滑块和按钮要像镶嵌在面板里的 3D 控件，不能像网页表单。

### 3. 离线对局

- 对局桌面是视觉基准：中心牌河、手牌、四方座位、顶部 HUD 都必须清晰。
- 3D richness 只允许集中在桌边、角标、座位外框、手牌托盘，中心牌河保持低纹理。
- 行动按钮栏和手牌托盘要有真实厚度和阴影，但不能遮挡牌。

### 4. 规则页

- 规则页像一本嵌入黑漆框的玩法手册，不是大块文字页面。
- 背景只提供低对比卷轴、示例牌桌和边框，正文区必须干净。
- 示例牌必须使用当前运行时牌图或引擎原生牌面，不由背景图生成可读牌面。

### 5. 统计页

- 统计页像赛后数据仪表盘：玉石数据槽、金属刻度、低对比趋势纹理。
- 数字、进度条和标签由 Godot 渲染，背景只提供仪表台和槽位。
- 保持暗色基调，但每一行的值域区必须可读。

### 6. 成就页

- 成就页像陈列柜或图鉴廊，奖章槽位要有立体框。
- 锁定成就不能过暗到不可辨识；已完成成就要有玉金高光。
- 背景不出现可读按钮、箭头或随机徽章文字。

### 7. 商店页

- 商店像国风宝阁和道具柜，货币区、道具行、购买按钮区分层明确。
- 资产图可以提供货架、柜台和道具氛围，但商品名称、价格和按钮由 Godot 渲染。
- 道具图标后续优先用 GPT 单独生成，不使用程序画的圆点或符号替代。

### 8. 联机大厅

- 联机大厅像四席雅间或月门庭院里的房间同步界面。
- 左侧输入区应是干净表单，右侧房间状态是桌席/房牌视觉。
- 当前优先删除输入区和连接区的程序轨迹装饰，保留 GPT 背景和必要可读底板。

### 9. 每日签到

- 每日签到像锦缎奖励册，有七日节点安全区。
- 背景可以有卷轴和奖励路线，但不要包含数字、文字或已领取标记。
- 签到按钮必须清晰，奖励节点由 Godot 控制状态。

### 10. 加载页

- 加载页是视觉标杆：月门、湖面、牌墙剪影、中心加载面板。
- 中心区域保持暗而干净，加载文字和进度由 Godot 渲染。
- 不额外添加程序月亮、云团或点线效果。

## GPT 生图 Prompt 交付规则

- 页面级 prompt 写入 `GPT_IMAGE_UI_DESIGN_PROMPTS.md`。
- 可执行 prompt 归档到 `garden-gpt-image-2/prompt/`。
- 每个 prompt 必须包含：
  - 输出路径和尺寸
  - 用途和接入页面
  - 安全区描述
  - 材质和光源
  - 禁止项
  - 不生成文字、不生成可读牌面、不生成按钮文案
- 图片生成后先作为候选图验收，再替换稳定资产，不直接覆盖用户已选定的 PNG。

## 验收标准

- `python3 tools/assemble_main.py --verify` 通过。
- `GODOT_SILENCE_ROOT_WARNING=1 godot --headless --path . -s scripts/ui_layout_smoke_test.gd` 通过。
- `GODOT_SILENCE_ROOT_WARNING=1 xvfb-run -a godot --path . -s scripts/page_screenshot_capture.gd` 产出 10 张截图。
- `python3 scripts/ui_screenshot_manifest_check.py` 通过。
- `build/qa/pages/contact_sheet.jpg` 中主菜单、对局、联机大厅、加载页风格统一，没有明显程序画的点线、轨迹或调试色块。
- `assets/illustrations/` 根目录没有未登记 PNG，所有运行时 GPT PNG 都有 `.import`。
