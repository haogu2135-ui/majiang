# Mahjong Tile Asset Brief

This file tracks the tile-face asset decision for `assets/tiles/*.png`.

Status: GPT-only tile replacement is allowed, but playable tile faces are
currently frozen until every generated candidate can be verified.

Reason: tile faces must match real mahjong markings exactly enough for gameplay
recognition. Current text-to-image generation is acceptable for decorative UI
art, but playable tiles need stricter acceptance: exact suit counts, Chinese
glyphs, wind/dragon characters, and flower/season labels. Existing runtime
tile PNGs are kept as frozen assets until a GPT candidate set passes those
checks.

Current source policy: do not rebuild playable tiles with non-GPT scripts.
The old local generation/import scripts have been deleted. Future replacement
must use `tools/regenerate_tiles_with_gpt.sh` or the `gpt-image-2` prompt flow,
then manually and programmatically verify every tile before importing it.

Hard reference rule: every GPT tile candidate must be generated by editing the
current matching runtime sprite from `assets/tiles/<same filename>.png`. The
existing tile image is the authority for symbol identity, exact count,
placement, color order, Chinese character shape, flower numbering, and tile
face layout. Do not create playable mahjong tiles from text-only prompts or
from unrelated external references.

Guardrails:

- `tools/import_gpt_mahjong_tiles.py` only accepts GPT candidate PNGs.
- `tools/regenerate_tiles_with_gpt.sh` generates candidates through GPT and
  imports only those candidates.
- `tools/generate_gpt_mahjong_tiles.py --list` must show a
  `current_tile: assets/tiles/...` reference for every selected tile.
- Do not replace playable tile faces unless the GPT output has been verified
  tile-by-tile against real mahjong conventions.

The historical GPT-generation target is kept below only as a record of the
discarded direction.

## Global Tile Rules

- Output path: `assets/tiles/`
- Target size: `200x280` PNG RGBA for every tile.
- Generate one tile per image, front-facing orthographic view, centered with stable margins.
- Keep real mahjong conventions:
  - Wan/man tiles: Chinese numeral at top, red `萬`/`万` character motif below.
  - Sou/bamboo tiles: exact count of bamboo sticks, with conventional mahjong-style arrangements.
  - Pin/circle tiles: exact count of circles, with conventional mahjong-style arrangements.
  - Winds: East/South/West/North characters only.
  - Dragons: red center, green fa, white dragon blank/border tile.
  - Flowers/seasons: Spring/Summer/Autumn/Winter and Plum/Orchid/Bamboo/Chrysanthemum motifs matching the named flower/season.
- No extra tiles, hands, table scene, logos, watermarks, brand marks, or non-mahjong symbols.
- The tile may contain the required real mahjong character/symbol; avoid all other text.
- Style: premium Chinese guofeng mobile game art, ivory jade tile body, rounded bevel, subtle ink texture, warm gold rim, crisp engraved face art.
